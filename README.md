# 🎵 Sonic Engine

A high-performance, dark-themed web audio player designed for a sleek, tech-focused experience.

**🚀 Live Demo:** [https://kushangshah.github.io/sonic-engine-player/](https://kushangshah.github.io/sonic-engine-player/)

## ✨ Features
- **📁 Directory Explorer**: Navigate through your local music folders with a curved directory tree.
- **⚡ Optimized Engine**: Version 0.4 features debounced searching and DOM fragment injection for lag-free performance.
- **🌈 Neon Visuals**: Real-time audio frequency visualizer and a glowing waveform scrubber.
- **🎹 Keyboard Control**: Use `Space` for Play/Pause, `Arrow Keys` to navigate, and `Enter` to select tracks.
- **🎲 Smart Randomizer**: Non-repeating shuffle for a fresh listening experience.

## 🚀 Quick Start
1. Download the `index.html` file.
2. Open it in any modern web browser.
3. Click **"Choose Directory"** and select your music folder.

## 🛠️ Tech Stack
- **HTML5 / CSS3** (Custom Neon UI)
- **JavaScript (ES6+)**
- **Web Audio API** (Real-time analysis & playback)
